# Проект: LMS для обучения персонала

Полная спецификация: docs/SPEC.md
Статус и список задач: PROGRESS.md

## Правила работы

1. В начале любой сессии сначала прочитай PROGRESS.md целиком.
2. Возьми в работу первую задачу без [x]. Делай только её, не трогай другие пункты списка.
3. Перед началом прочитай в docs/SPEC.md разделы, указанные в этой задаче.
4. Затрагивай только файлы и папки, указанные в поле «Куда» этой задачи.
   Не переписывай уже готовые модули без явной просьбы.
5. После того как код написан — запусти тесты и сборку, ошибки исправь сам.
6. Когда выполнен критерий «Готово когда» — отметь задачу [x] в PROGRESS.md
   и одной строкой допиши, что именно сделано.
7. Если для задачи не хватает решения, которого нет в docs/SPEC.md —
   останови работу и спроси, не додумывай сам.
8. Не начинай следующую задачу без запроса — сообщи, что текущая готова, и жди.
