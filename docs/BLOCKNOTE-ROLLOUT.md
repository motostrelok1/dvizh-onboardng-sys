# BlockNote: приёмка и первый production rollout

Статус: **кандидат на релиз, ещё не развернут на VDS**. Этот документ
применять только после зелёных PR checks и утверждения maintenance window.
На сервере уже действует автоматический деплой, но он намеренно пропускает
коммиты с изменениями схемы БД и package-lock: для первой установки BN
требуется разовая полная процедура.

## Состав релиза

- Зависимости BlockNote 0.55.0 и Mantine 8.3.18 закреплены в lockfile.
  Лицензия BlockNote — MPL-2.0; XL-модули не используются.
- Миграция `1700000018000_rich_lesson_content.cjs` добавляет два столбца
  `lessons.content_blocks JSONB NULL` и `content_revision INTEGER NOT NULL DEFAULT 0`.
  Старый `text_content` не изменяется, не удаляется, миграция обратно
  без экспорта новых материалов **не выполнять**.
- `PATCH /api/admin/lessons/:id/blocks` с optimistic revision/409,
  доступ только администратору, server-side JSON validation.
- Редактор BlockNote: тексты, списки, таблицы, заголовки, форматирование,
  эмодзи, пять учебных callout-блоков и JPG/PNG загрузка в приватное storage.
- Картинки доступны по `/api/attachments/:id/inline` только после проверки
  прав на курс и не создают `attachment_download` событий.
- Предпросмотр администратора не создаёт реальные попытки тестирования.
- Сотрудник видит тот же форматированный урок в режиме только чтения.
- Старые уроки открываются как plain text paragraphs без перезаписи базы.

## До релиза (обязательно)

1. PR CI: сборка frontend/backend, PostgreSQL 16 migrations+re-run,
   backend/API/roles, проверка bash syntax.
2. Проверить достаточное место для tar каталога `node_modules`, DB dump,
   uploads и двух frontend/backend сборок. Последний архив backup не
   должен быть единственным или храниться только на VDS.
3. Остановить запись пользователями в maintenance window. Отдельные сайты
   `dvizh-school.ru`/`edu.dvizh-school.ru` не трогать.
4. Прод-миграцию никогда не запускать из стандартного auto workflow.
5. Зафиксировать SHA с зелёным CI; не запускать непроверенный main.

## Одна команда на VDS (оператор root, только после готовности релиза)

```bash
cd /opt/lms && git fetch origin main && bash <(git show origin/main:deploy/blocknote-release.sh) "$(git rev-parse origin/main)"
```

Скрипт **не запускать заранее**. Он проверяет чистый checkout/fast-forward,
одну ожидаемую миграцию, останавливает только `lms.service`, делает backup
PostgreSQL/uploads/старой статики/backend/node_modules, выполняет `npm ci`,
сборку, read-only preflight, миграцию, публикацию и проверки
`/health`, `/health/db`, HTTPS. При ошибке восстанавливает прежние сборки,
зависимости и пытается вернуть сервис. База при частично выполненной
additive-миграции не возвращается автоматически. Сохраняется флаг
`RECONCILE-BEFORE-NEXT-DEPLOY`, блокирующий новые обновления при
несогласованном checkout.

**Важно:** команда запускает настоящий production rollout с возможным
перерывом доступа и требует согласования. Не вводите секреты в чат.

## Финальная пользовательская приёмка BN-07

Проводится владельцем **после** полного завершения всех задач, а не
между PR. Для проверок использовать отдельный учебный курс, а не
существующие материалы реальных сотрудников.

- [ ] Открыть старый текстовый урок, убедиться в сохранении абзацев,
      пустых строк, спецсимволов, эмодзи, HTML как безопасного текста.
- [ ] Создать новый урок: H1/H2/H3, жирный, курсив, ссылки, чек-листы,
      таблицу, цитату, блок «Важно», «Совет», «Предупреждение»,
      «Пример», «Запомните».
- [ ] Добавить PNG/JPEG через файл, Ctrl+V и drag/drop; проверить подпись,
      изменение размера, сохранение и просмотр сотрудником. Проверить
      ограничения размера и отказ в доступе без назначения.
- [ ] Автосохранение при отключённой/включённой сети, ручной повтор,
      одновременные вкладки → конфликт 409 без тихой перезаписи.
- [ ] Админский preview и демотест не меняют статистику, попытки и события.
- [ ] Сотрудник видит лишь доступный ему курс; другой пользователь не
      скачивает/не видит чужую картинку.
- [ ] Мобильный экран iPhone Safari/Chrome, PWA обновление после деплоя,
      большие уроки, 320–768 px, клавиатурная навигация.
- [ ] Повторно открыть, свернуть/развернуть, переставить уроки и модули,
      убедиться в сохранении форматирования.

Результаты тестирования занести в `PROGRESS.md` после проведения, не
отмечать авансом.
