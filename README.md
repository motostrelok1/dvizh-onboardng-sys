# LMS

## Запуск (разработка)

```bash
docker compose up -d          # поднять PostgreSQL

cp server/.env.example server/.env
cd server && npm install
npm run migrate               # создать таблицы
npm run dev                   # http://localhost:3000/health

cd ../client && npm install && npm run dev  # http://localhost:5173
```

Откройте http://localhost:5173 — должно показать «Статус сервера: ok».
Проверка БД: http://localhost:3000/health/db
Список таблиц: http://localhost:3000/health/tables

## Проверка входа (пока нет админки)

```bash
npm run seed:admin -- "Имя Фамилия" admin@example.com
npm run invite -- <user_id из вывода выше>
```

Полученный токен открывается как `GET /auth/invitations/<token>` (проверка),
`POST /auth/invitations/<token>/accept` с `{"password":"..."}` задаёт пароль
и сразу логинит (cookie `lms_session`). Дальше — `POST /auth/login`,
`POST /auth/logout`, `GET /auth/me`.

## Админка (этап 3)

```bash
cd client && npm install && npm run dev
```

Откройте http://localhost:5173 — экран входа. Войдите под администратором,
созданным через `npm run seed:admin` (см. выше). На вкладках: сотрудники
(создание, отдел, часовой пояс, выпуск ссылки-приглашения), отделы, группы
(состав участников через чекбоксы).

## Курсы (этап 4)

Вкладка «Курсы» в админке: создание курса, статус/доступ, дерево
модуль → урок, порядок модулей и уроков (кнопки ↑/↓), у урока — текст,
видео (провайдер + ссылка/идентификатор) и дополнительные материалы
(загрузка файлов, разрешены pdf/doc/docx/xls/xlsx/png/jpg, до 50 МБ —
список и лимит настроятся, когда решится открытый вопрос из SPEC §18).

## Тесты (этап 5)

В редакторе курса у каждого модуля и у каждого урока — кнопка «+ добавить
тест» (не больше одного на модуль/урок). Внутри теста: настройки (число
попыток, показ правильных ответов, проходной балл), вопросы с чекбоксом
«несколько верных», варианты ответов с чекбоксом «верный».
